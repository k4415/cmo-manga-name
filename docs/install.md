# 導入ガイド

2026-09-11／0.1.4-trial

## ZIPから、AIに導入を頼む（試験配布の基本）

ZIPを展開し、README.mdがあるフォルダをエージェントから開ける場所に置きます。SKILL.mdだけを取り出さず、フォルダ一式を保持してください。次をコピーし、最後に展開先フォルダの場所を伝えます。

```text
このフォルダのREADME.mdとdocs/install.mdを読み、同梱の漫画ネーム制作スキルをこの環境へ導入してください。
利用中のエージェントに合う設置先を確認し、skills/cmo-manga-nameフォルダを丸ごと設置してください。
同名スキルが既にある場合は、版と実体・リンク先を確認し、上書きせず更新ガイドに沿ってください。
APIキーやMCP接続の新設は不要です。既存の作品やエージェント設定を変更しないでください。
設置後、読んだSKILL.mdの実パスと版、参照ファイルの有無、起動方法を教えてください。
展開先：
```

エージェントがファイルにアクセスできない場合は、作業フォルダとして開いてから依頼してください。ZIPをチャットへ添付しただけでは展開・設置が完了したとは限りません。

## 手動で設置する場合

展開した `skills/cmo-manga-name` を、以下のいずれかへ丸ごとコピーします。対象エージェント1つだけなら、その行だけで十分です。

|利用環境|個人用の設置先|
|---|---|
|Codex|`~/.agents/skills/cmo-manga-name/`|
|Claude Code|`~/.claude/skills/cmo-manga-name/`|

`~` は自分のホームフォルダです。Windowsでは自分のユーザープロファイル配下の同名フォルダとして扱い、利用環境の対応を確認します。隠しフォルダの表示が難しければ上の依頼文を使ってください。両方へ入れる場合は同じ版をコピーし、更新時も両方を揃えます。

Codexの既存環境では `~/.codex/skills/` に設置されている場合もあります。重複して作らず、既存の検出先を確認してください。プロジェクト専用のスキルやプラグインと同名のものがある場合も、どれが起動したか実パスを照合します。

設置後は新しい会話で、次を依頼します。候補に現れなければエージェントを再起動します。

- Codex：`$cmo-manga-name を使って漫画記事のネームを作りたい。最初に読み込んだスキルの版を教えて。`
- Claude Code：`/cmo-manga-name 漫画記事のネームを作りたい。最初に読み込んだスキルの版を教えて。`

期待する版は `0.1.4-trial`。本文、referencesフォルダ、scripts/storyboard.pyが揃っていることを確認します。Pythonがなければその検証だけ未実行と伝え、脚本制作を進めます。
