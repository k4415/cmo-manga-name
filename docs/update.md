# 更新と元の版へ戻す

2026-09-11／0.1.4-trial

1. 現在読み込んでいるスキルの実パスと版をエージェントに確認させます。シンボリックリンクの場合は参照元を確認します。
2. 提供された新版の変更履歴を読みます。既存作品が自動で書き換わる更新ではありません。
3. 現在のフォルダ一式を、エージェントがスキルを探索しないバックアップ用フォルダへコピーします。SKILL.mdを残したバックアップをskills配下へ置くと、重複検出の原因になります。
4. 自分で加えたルールがある場合は差分を確認してから更新します。同名の設置先がある時に黙って上書きしません。
5. 新版のフォルダ一式へ置き換えます。複数エージェントを使う場合は各設置先を揃えます。
6. 新しい会話で読み込んだ版と実パスを確認し、短い制作依頼を試します。

元へ戻す場合は、現行版をバックアップしてから、保存した旧版一式を元の設置先へ戻します。作品のシート・ネーム・画像は別管理のため、スキルを戻すだけでは変更しません。

配布原本のシートを更新しても、利用者が持つシートコピーやローカルスキルは自動更新されません。「案内タブの更新」と「スキルの更新」を分けて行います。指定された版のZIPを使い、開発ブランチの最新版を毎回自動取得する運用はしません。
