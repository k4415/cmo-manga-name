# 困ったとき

2026-09-11／0.1.4-trial

|症状|確認と対処|
|---|---|
|ダウンロードできない|READMEの配布ページから添付ZIPを選ぶ。公開版の取得にログインは不要。社内ネットワークでGitHubが制限される場合は提供元へ連絡する|
|スキルが出てこない|設置先、フォルダの二重入れ、SKILL.mdと付属資料の有無を確認。新しい会話／再起動で確認|
|古いルールで動く|読み込んだ実パスと版を照合。直接設置・プロジェクト内・プラグインの同名スキルを確認|
|Google Sheetsへ接続できない|ネーム制作を続け、TSVを受け取る。シートで新規タブとしてインポートし、タブ区切り・文字列扱い・改行を確認|
|TSVで列や改行が崩れる|ファイルのインポートを試す。解消しなければ文字列型XLSXを依頼。形式エラーを無視して使わない|
|Pythonがない|脚本・人物設計を進める。利用可能な別の表計算ツールで出力し、未実行の形式検証を明記する|
|CMO取込で文字が欠ける|NA・SE・注釈の本文が「で始まっていないか確認する。取込側が括弧として除去する。『』に直して形式検証を再実行する|
|シートに関係ない文が貼られた|貼付直前にクリップボードが別の内容へ置き換わった可能性。正本を再ロードして同じ範囲へ貼り直し、全セルを照合する|
|CMO MCPがない|人物設計と4列を手動入力する。画風はCMO AI Pro側で選択する|
|画像生成が止まった|対象作品・ジョブ・成功分を照合し、残りだけ再開。結果不明のまま別依頼で全件生成し直さない|
|商品資料が足りない|不足箇所を確認待ちにし、独立して作れる場面から進める。実績や販売条件を仮の事実として足さない|

試用で問題が起きたら、使用エージェント、スキル版、工程、期待した動き、実際の動き、該当箇所を提供元へ伝えてください。顧客情報・認証情報・未公開原稿をそのまま公開Issueへ貼らないでください。
