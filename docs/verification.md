## エージェントでの短い制作テスト

macOS上のCodex CLI 0.146.0とClaude Code 2.1.263で、ZIPを別々の作業フォルダへ展開し、プロジェクト用のスキル配置（Codexは `.agents/skills`、Claude Codeは `.claude/skills`）で0.1.7-betaを読み込んだ。

外部連携を使用しない設定で、架空の紙ノートを題材に2画像・各1コマの漫画記事を制作。両方でネームJSON／TSV、人物設計MD／JSON、制作メモを作成し、同梱補助ツールの形式検証、TSVのセル読戻し、人物名集合の一致を確認した。通常のユーザー設定・フックの影響はこのテストに含めていない。これはAIサービスへの接続を使った制作テストであり、完全オフラインでのAI動作確認ではない。

この確認は、隔離したプロジェクトでの短い制作テスト。利用者のホームフォルダへの新規設置、全編制作、人間による品質採用の証明ではない。試験原稿は配布物へ含めない。
