# 試用と改善

最終更新: 2026-09-11

ユーザーがスキルの改善・振り返りを求めた場合に使う。制作のたびに長いアンケートを強制しない。

残す情報: スキル版／使用エージェント／媒体／制作ブリーフ／AI初稿／ユーザーの修正指示／確定稿／問題が起きた工程／制作時間・修正回数／保存・生成の実施範囲。必要な範囲だけ、作品フォルダへ記録する。

|観点|短い確認|
|---|---|
|意図|狙った感情・欲求を汲み取れたか。どの台詞でずれたか|
|脚本|特に前半の会話が自然か。結末まで読み進めたいか|
|納得|商品を選ぶ理由・根拠・CTAがつながるか|
|演出|実際に描けるか、読みやすいか、人物が安定するか|
|効率|不要な質問・作り直し・形式修正があったか|
|引き継ぎ|シート・人物設計・CMO取込で再入力や欠落が起きたか|

修正を「今回の明示指定／案件固有の設定・表現／他案件にも使える判断」に分ける。文字数・秒数や採用した台詞をそのまま万能の型にせず、どういう条件で統合・分割・NA化・演出変更が有効だったかを抽出する。冒頭の感情も一種類に固定しない。

作品固有の好みと、複数案件に適用できる原因・ルールを分ける。ユーザーの改善依頼に応じ、該当する本文・参照資料・補助ツールだけを修正し、版を上げる。承認済みの別作品へ自動反映しない。

人間が採用した見本だけを将来の配布候補にする。試験出力を完成見本と表示しない。配布へ進む時に、両エージェントでの通し制作、利用者コピーへの保存、CMO実取込・生成、人物の識別、記事と動画の読みやすさ、第三者資料への酷似、配布一式を確認する。制作の受入と広告効果の実測は別に残す。
