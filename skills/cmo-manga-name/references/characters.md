# キャラクター設計

最終更新: 2026-09-14

人物はこのスキルで設計し、ネーム完成後にCMO AI Proで画像を作る。未登録でも脚本・最終4列を完成できる。既存人物を使う依頼ではその設定を保持する。

## 脚本と設計

脚本の初稿前に、作品内の確定名、役割、関係、性格の芯、本音のテンション、口癖・語尾を整理し、声の見本3行を作る（dialogue-and-emotion.md「人物の声を先に決める」）。演出段階で外見と衣装を確定する。特定の人種・性別・外見を役割だけから必須にせず、ユーザー指定と場面の必要性から提案する。

確定名は短く識別できるものを提案する。4列で使う区切りの「・」や「」（）、改行を含む名前、20文字を超える発話名は取込用の確定名を相談し、無断で置換・省略しない。声だけで一度も描かない人物は名前・役割・口調と「画面登場なし」を記録し、画像生成対象へ自動で含めない。

人物ごとの設計書には以下を持たせる。

- 確定名／役割／他者との関係／性格の芯・本音のテンション・口癖・語尾／声の見本3行。心の声と会話で口調が違う人物は、その描き分けを明記する。
- 年齢または見た目年齢、必要な場合の性別表現。
- 顔立ち、髪形・髪色、体格、衣装と配色、靴・小物。
- 他の人物と見分ける識別点。画面上で使うものを優先する。
- 全編の固定条件と、場面で変わる状態・表情・衣装。人物全体を一時的な泣き顔等で固定しない。
- CMO AI Proへ渡す生成用指示文。画風指定は含めず、外見・衣装・識別点・固定条件をまとまった文章にする。

生成用指示に「第三者のキャラクターの複製・酷似を避け、ここに記した人物として制作する」を含める。作品内の指定スタイルはCMO AI Pro側から継承する。権利リスクのある参考漫画画像をキャラ生成へ送らない。

## 納品

`characters.md` を人物ごとにコピーしやすく作り、同じ内容で `characters.json` も作る。

JSONの形（値は案件の設計で埋める。以下はフィールド説明）:

```json
{
  "version": "人物設計の版",
  "characters": [{
    "name": "作品内の確定名",
    "role": "物語での役割",
    "age": "年齢または見た目年齢。未指定なら空文字",
    "gender": "必要な場合の表現。未指定なら空文字",
    "relationship": "関係",
    "personality_and_voice": "性格の芯、本音のテンション、口癖・語尾、心の声と会話の描き分け",
    "voice_samples": ["声の見本1", "声の見本2", "声の見本3"],
    "appearance": "顔・髪・体格",
    "clothing": "衣装・配色・小物",
    "distinctive_features": "識別点",
    "fixed_traits": "固定条件",
    "scene_variations": "場面による変化",
    "instructions": "そのまま入力できる生成用指示文"
  }]
}
```

未生成の実IDを創作しない。最終出力時は `characters.json` の全nameと `storyboard.json` のcharactersをプログラムで抽出し、重複がなく集合が一致することを照合する。4列のB列と話者名は補助ツールでこの確定名と照合する。表記を変える必要があれば対応箇所を示し、承認済み本文の意味を変えず整合させる。MCPの入力長は実行時の現行スキーマに対して機械的に検査し、長さのために承認済み条件を無断で切り捨てない。

生成を依頼されたら [mcp-characters.md](mcp-characters.md) を読み、実IDを別の `character-generation-state.json` に記録する。ネーム完成へのOKと生成依頼は区別する。
