# コマ作画の引き渡しと実画像確認

最終更新: 2026-09-11

ユーザーがコマ作画・画像修正・漫画完成まで依頼した場合に読む。ネーム制作のみでは実行しない。既知の対象・承認済み原稿・依頼範囲を引き継ぐ。公開や広告配信は別の依頼範囲として扱う。

## 生成前

接続先の現行ツールと入力スキーマを確認し、対象作品・作画スタイル・人物・既存コマの状態を読む。未公開のツール名や実IDを作らない。承認済み原稿のサイズ・文字・人物・コマ割り・構図を対応させ、登録後に読み戻して照合する。複数内部コマの画角が異なる場合は各区画のD列指定を保持し、一つの設定値で上書きしない。

[output-and-save.md](output-and-save.md) の素材対応に従い、使用箇所ごとの参照設定を確認する。各D列に単独で必要な状態があること、参照素材と脚本が食い違わないことを点検する。

依頼キー・登録済みID・ジョブ・生成版・選択状態を作品の制作記録へ残す。通信エラーやタイムアウトで成功不明なら状態を照会してから再開し、登録・生成を重複実行しない。失敗・上限到達は既存成功分を保持し、必要な対象だけを再試行する。画面の操作がない機能は手動用指示として渡す。

## 実画像を確認する

全編を実際の掲載順と想定表示幅で確認し、文字やロゴ等の細部は必要な箇所を拡大する。少数の成功画像や生成成功ステータスだけで全編確認済みにしない。

- 文字: 原稿の欠落・追加・重複・誤字、話者としっぽ、読み順、注釈の可読性。画面の小文字や数値も確認する。
- 同一性と連続性: 人物、商品、場所、小道具、所持する手、通話や作例内の人物。前後の画像と照合する。
- 利用と変化: 説明される対象が絵にあるか、変化が見分けられるか。未指定の実績や効果を絵で補っていないか。
- 参考素材: 指定箇所に反映されたか、保持すべき形・色・文字が合うか、別作品の内容が混入していないか。
- 演出: 主役と感情の強弱が伝わり、装飾・文字・内部コマ数が判断材料を隠していないか。

問題は画像・版・問題箇所・修正目的を短く記録する。機械的な本文照合は保存データの検証であり、画像内の文字一致の証明とは区別する。

## 修正と完成確認

絵だけの問題は該当画像の限定修正を優先し、変更対象と保持する文字・人物・構図を具体的に指示する。元画像と修正版を区別し、前後の画像と照合する。修正に伴う別の変化も確認する。承認済み台詞を修正の都合で書き換えない。脚本変更が必要なら差分と理由を提示する。文字は絵と一体生成し、後合成しない。

同じ問題が続く場合は、不足する設定・参照の不一致・一枚に含めた情報量を見直す。解決条件が変わらないまま再生成を繰り返さず、残る問題と必要な情報・選択肢を返す。

完成時は、全対象画像の成功と選択状態、番号・順序・欠落、修正が採用版へ反映されたことを確認する。書き出した場合はファイル件数・整合性と修正後の版を照合する。原画像や本文の掲載ブロックがある記事はその実施範囲も報告し、漫画画像だけの完成を記事全体の完成と取り違えない。自動選択、AIの確認、人間の受入、広告成果を別々に記録する。
