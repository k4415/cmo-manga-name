# 漫画ネーム制作スキル

漫画記事・漫画ショート動画の脚本、演出、キャラクター設計を、Claude Code／Codexと相談しながら作るスキルです。CMO AI Proへ引き継ぐ4列のネームを出力します。

**版：0.1.7-beta／ベータ版（無料・商用利用可）／2026-09-16**

個人・法人を問わず、自社広告や顧客向けの商用制作にも無料で使えます。ローカルのCodexまたはClaude Codeが必要です。AIエージェント・画像生成等の外部サービス料金は別途利用者負担です。

## はじめる

1. [ベータ版ZIPをダウンロード](https://github.com/k4415/cmo-manga-name/releases/download/v0.1.7-beta/cmo-manga-name-0.1.7-beta.zip)して展開します。GitHubアカウントは不要です。
2. [導入ガイド](docs/install.md)の依頼文を、お使いのローカルAIエージェントへ渡します。
3. [最初の制作依頼](docs/quickstart.md)をコピーして、分かる項目だけ記入します。
4. 脚本を調整し、演出・人物設計を確認したら、ご自身のスプレッドシートへの保存を依頼します。

[配布ページ](https://github.com/k4415/cmo-manga-name/releases/tag/v0.1.7-beta)には、版の説明とファイル照合用のSHA256SUMS.txtがあります。添付の配布専用ZIPをご利用ください。

配布ページのSHA256SUMS.txtはZIP自体のハッシュ、ZIP内のSHA256SUMS.txtは同梱ファイルごとのハッシュです。

## できること

- 狙う感情・欲求に合う場面と自然な会話を考え、長短の台詞や場面転換を調整する。
- 構図・距離・角度・漫画的演出と、前後の人物・小道具の連続性を設計する。
- 漫画記事、60秒を初期値とするショート動画、指定された別用途に合わせる。
- 利用者のシートに新規タブを作る。接続できない場合は貼付・取込用ファイルを渡す。
- CMO AI Proで使う人物設計を作る。生成も依頼された場合、利用可能なMCP・ブラウザ操作、または手動入力へ引き継ぐ。

## 用意するもの

- ファイルを扱えるローカルのClaude CodeまたはCodex。
- 商品資料、ターゲット、目的行動。未定部分は相談できます。
- シート保存をする場合は、ご自身のGoogleスプレッドシートと編集権限。
- CMO AI Proで画像生成する場合は、同サービスを利用できる環境。

Google連携・CMO AI Pro MCPは必須ではありません。既存の接続を使用します。Python 3は形式検証の補助用で、導入や脚本相談の必須条件ではありません。APIキーを配布物やシートへ貼る必要はありません。

作画スタイルはCMO AI Proで選びます。人物画像も同サービスで生成します。4列の貼付は画像生成の前工程であり、完成動画の編集や広告配信まで自動で完了するものではありません。
